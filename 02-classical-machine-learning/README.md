# 📘 Phase 2 — Classical Machine Learning

Phase 2 introduces **classical machine learning**, where models learn patterns directly from structured data using statistical methods rather than deep neural networks.

This phase is essential because it teaches how machines “learn from data” in the most interpretable and controllable way.

---

# 🎯 Purpose of This Phase

Before moving into deep learning, you must understand:

- how models generalize from data
- how predictions are evaluated
- how overfitting happens
- how features influence performance
- how training pipelines are structured

Classical ML is the foundation for:
- deep learning training workflows
- data preprocessing pipelines
- evaluation methodology
- real-world AI systems in production

---

# 🧠 What You Will Learn

By completing this phase, you will understand:

- how supervised learning works in practice
- how to train classification and regression models
- how to evaluate model performance properly
- how to detect and fix overfitting
- how feature engineering impacts results
- how to build full ML pipelines using Scikit-learn

---

# ⚙️ Core Topics Covered

## 📊 Supervised Learning
- Learning from labeled data
- Mapping inputs → outputs

## 📈 Classification vs Regression
- Classification → discrete outputs (spam / not spam)
- Regression → continuous outputs (price prediction)

## 🧪 Train / Validation / Test Splits
- Preventing data leakage
- Measuring generalization

## 📉 Overfitting & Underfitting
- Model complexity vs performance
- Bias-variance tradeoff

## 🧩 Feature Engineering
- Converting raw data into useful signals
- Encoding categorical variables
- Scaling numerical features

## 📏 Evaluation Metrics
- Accuracy
- Precision / Recall / F1-score
- Mean Squared Error (MSE)

## 🧼 Data Preprocessing
- Handling missing values
- Normalization / scaling
- Encoding categorical data
