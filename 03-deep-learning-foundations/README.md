# 🧠 Phase 3 — Deep Learning Foundations

Phase 3 introduces **deep learning**, where models learn hierarchical representations of data using neural networks.

This is the turning point in the AI roadmap where you move from:
- manual feature engineering (Classical ML)
to
- automatic feature learning (Deep Learning)

---

# 🎯 Purpose of This Phase

The goal of Phase 3 is to deeply understand:

- how neural networks learn from data
- how backpropagation updates weights
- how convolution works for images
- how sequence models process text
- how attention enables transformers
- how GPUs accelerate training

By the end of this phase, you will be able to build and train neural networks from scratch using PyTorch.

---

# 🧠 What You Will Learn

You will develop intuition for:

- forward and backward propagation
- gradient descent in high-dimensional spaces
- activation functions and non-linearity
- convolutional feature extraction
- sequence modeling (RNNs, LSTMs)
- attention mechanisms
- transformer architectures
- transfer learning with pretrained models
- GPU-based training workflows

---

# 🏗️ Project Roadmap (5–10 Projects)

Each project is designed to progressively build deep learning intuition.

---

## 🟢 Project 1 — Neural Network From Scratch (NumPy)

### 🎯 Goal
Understand how neural networks actually work under the hood.

### Concepts
- forward propagation
- backpropagation
- gradient descent

### Outcome
A fully manual neural network trained without PyTorch.

---

## 🟢 Project 2 — MNIST Digit Classifier

### 🎯 Goal
Train your first real deep learning model.

### Concepts
- image classification
- dense neural networks
- loss functions

### Model
- simple feedforward network (PyTorch)

### Outcome
Classify handwritten digits (0–9).

---

## 🟢 Project 3 — Fashion-MNIST Classifier

### 🎯 Goal
Improve generalization and model evaluation.

### Concepts
- overfitting in deep learning
- regularization
- validation curves

### Model
- improved MLP or CNN baseline

---

## 🟡 Project 4 — CIFAR-10 Image Classifier (CNN Introduction)

### 🎯 Goal
Learn convolutional neural networks.

### Concepts
- convolution layers
- pooling
- feature extraction

### Model

---
